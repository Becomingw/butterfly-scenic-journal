# v1.1.0 验证范围

自动构建检查覆盖：必需路由与资源、每篇文章链接、导航链接、RSS/sitemap、统计和文章目录一致性、年度/星期/长度分组总和、影评草稿排除、评分与日期边界、HTML 转义、CMS schema、混合语言计数、闰日、同日多篇、GitHub 分页/排序/前十上限/失败回退与快照时间。

新增自动检查：碎碎念时间/跨年/同日顺序、草稿与未来日期排除、字词/配图独立统计、后台封面与碎碎念字段、菜单/资源和统计跳转链接。

发布前浏览器检查：桌面与手机宽度、明暗主题、首页插画、发布日历及文章/碎碎念跳转、碎碎念筛选/分页/灯箱、影视折叠、空项目/歌单提示、PJAX、无 JavaScript 的统计可读性，以及隔离测试后台的表单与预览。README 截图展示 Becomingw Blog 正式站；模板本身使用示例内容验证。

真实 Gitea OAuth 登录和真实歌曲播放需要部署者自己的账号/音源配置，不属于占位模板的通过项。模板不包括个人电影海报或音乐文件。

CI 使用固定 Node 22.23.4 容器重新执行 `npm ci` 和所有构建检查。发布产物来自 Git 标签；不同日期构建的统计时间可能不同。
