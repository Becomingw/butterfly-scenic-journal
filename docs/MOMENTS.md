# 碎碎念

前台入口：**更多 → 碎碎念**（`/moments/`）。支持关键词、年份点选、每页 12 条、配图灯箱和直接跳转到某条记录；关闭 JavaScript 时全部记录仍可阅读。切换页面使用 PJAX，监听器随页面清理。

## 写一条记录

登录 `/admin/`，选择 **碎碎念**，填写备注、时间及正文或配图。也可以直接创建 `content/moments/*.md`：

```yaml
---
title: 后台列表里的备注
date: "2026-01-01T10:00:00+08:00"
published: true
images:
  - url: /img/journal-landscape.webp
    alt: 山间的一小片风景
---
一些不必写成长文的小事。
```

`title` 仅作为后台列表备注和新文件名来源，前台展示正文。`date` 必须携带时区，如 `Z` 或 `+08:00`。文件名支持 Unicode 字母、数字、下划线和连字符；发布后尽量保留文件名，以维持固定链接。

| 字段 | 用途 |
| --- | --- |
| `author` / `avatar` | 可选；留空使用站点作者和头像 |
| `images` | 可选多图列表，每项包含 `url` 和可选 `alt` |
| `music_url` | 可选配乐；网易云 HTTPS `/outchain/player` 自动内嵌并关闭 autoplay，其他 HTTP(S) 链接作为跳转 |
| `published` | `false` 表示不公开，默认公开 |
| Markdown 正文 | 与配图、配乐至少填写一项，可只发图 |

后台图片上传至 `source/images/uploads/`。时间预览采用浏览器时区；前台与统计使用 `_config.yml` 中的 `timezone`。未来记录仅在到期后的下一次构建中显示，需配置定时构建才能定时发布。

## 文章历程

独立展示数量、字词、配图次数、活跃天数、年度分布、第一条/最近一条和最长连续记录。正文中的图片和配图库均计数，头像不计入；同一图片重复使用按引用次数计算。

日期按站点时区归日，同一天多条只占一个活跃日，同日的先后顺序使用精确时间戳。文章与碎碎念各自统计，不把两类内容相加当作文章数。日历切换内容时默认展示该类内容最近有记录的年份。

统计随发布构建更新，JSON 位于 `/journey-data.json` 的 `moments` 字段。检查命令：`npm run build && npm run check`。模板中的三条记录是示例，可编辑或删除；没有碎碎念时页面会展示空状态。
