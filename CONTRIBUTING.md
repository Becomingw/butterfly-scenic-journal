# Contributing

Use Node from `.nvmrc`, install with `npm ci`, and verify with `npm run build && npm run check`.

Keep customizations outside `node_modules/hexo-theme-butterfly`. Preserve progressive enhancement, keyboard access, reduced motion, mobile layouts and dark mode. Re-test PJAX lifecycle changes for duplicate listeners and players.

Use fictional examples and original or clearly licensed artwork. Do not include personal posts, credentials, account identifiers, internal service URLs or production deployment paths. Describe dependency updates explicitly; the v1 baseline is deliberately pinned.

For bugs, include the commit, Node version, browser, viewport, steps and relevant build errors. For browser-facing changes, attach desktop/mobile screenshots and note checks performed.
